# NEXT Command Center

The Restaurant NEXT Command Center: every NEXT store on a map, each store's 3D view and
drive-thru, its orders, network, incidents and cases, and the Agent Q assistant.

## Requirements

- Grafana 13.2.0 or later.
- A Google Maps JavaScript API key for the maps, restricted to your Grafana's URL.

## Getting started

1. Enable the app, then open its **Configuration** tab.
2. Enter the Google Maps API key, and optionally the agent flow URL, under **Map and agent
   settings** and save. Without a flow URL, Agent Q gives example answers.
3. Open it from **More apps → NEXT Command Center**.

The data shown is example data for now.
